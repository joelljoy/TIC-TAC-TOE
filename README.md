# 🎮 Tic-Tac-Toe Game

A graphical Tic-Tac-Toe game built using Java Swing that allows two players to compete in an interactive desktop environment. The game includes player customization, real-time score tracking, win detection, draw handling and a clean graphical user interface.

---

## 🚀 Features

### 🎯 Interactive Gameplay

* Two-player mode
* Turn-based gameplay
* Simple and intuitive interface
* Real-time move updates

### 👤 Player Customization

* Enter custom player names
* Automatic assignment of X and O symbols
* Personalized game experience

### 🏆 Score Tracking

* Persistent scoreboard during gameplay
* Separate score tracking for both players
* Automatic score updates after each win

### ✅ Win Detection

The game automatically detects:

* Horizontal wins
* Vertical wins
* Diagonal wins

### 🤝 Draw Detection

* Detects tied matches
* Displays draw notifications
* Automatically resets board

### 🔄 Board Reset

* Automatic reset after win
* Automatic reset after draw
* Continue playing without restarting application

### 📢 Game Notifications

* Winner announcements
* Draw messages
* Invalid move warnings
* Turn indicators

## 🎮 Gameplay Flow

1. Launch the application
2. Enter Player X name
3. Enter Player O name
4. Take turns placing X and O
5. First player to complete a row, column, or diagonal wins
6. Scores update automatically
7. Board resets for the next round
